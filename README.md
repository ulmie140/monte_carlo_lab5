Оптимизация входного контроля (Метод Монте-Карло)



Проект представляет собой веб-приложение для моделирования производственных издержек по методу Монте-Карло. Разработан в рамках лабораторной работы №5 по дисциплине "Базы знаний и поддержка принятия решений".



Описание задачи

На предприятие поступают партии резисторов с определенной долей брака. Цель - определить оптимальную долю партий для входного контроля, чтобы минимизировать суммарные издержки на проверку, подгонку и замену бракованных деталей в готовых изделиях.



Технический стек и Архитектура

Проект построен на принципах чистой архитектуры (Clean Architecture):

Domain (`src/domain/lfsr.py`): Математический генератор псевдослучайных чисел на основе 32-битного регистра сдвига (LFSR) с полиномом №5.

Service (`src/services/simulation.py`): Бизнес-логика симуляции Монте-Карло.

Web (`src/web/`): REST API на Flask и адаптивный фронтенд с использованием Tailwind CSS и Chart.js для визуализации графиков.



Запуск проекта

1. Запустите сервер: `python main.py`

2. Откройте в браузере: `http://127.0.0.1:5000`
